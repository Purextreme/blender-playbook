# 🍊 橘子 · Visibility Scanner

非破坏性的对象级可见性分类插件。实际验证版本：Blender 5.2.2 LTS；最低声明版本为 4.2，其他版本尚未实测。

## 安装与使用

1. 下载仓库的 `dist/orange_visibility_scanner-1.0.1.zip`。
2. 在 `Edit > Preferences > Add-ons > Install from Disk` 安装 ZIP，启用 `🍊 橘子 · Visibility Scanner`。
3. 回到 3D 视图，按 `N`，打开 `🍊 橘子` 页签。
4. 范围选择可见场景，或所选对象及其后代组成的装配体。确保扫描范围包含要参与遮挡的外壳。
5. 使用默认 `GPU + BVH 复核`，点击检测并分类。扫描中可按 `Esc` 取消，取消不会替换已有分类。

结果位于 `VIS_SCAN_RESULTS` 下：

- `VIS_可见_Visible`：发现至少一处外部可见部分。
- `VIS_内部候选_Candidates`：本帧采样中未发现可见部分，供人工复核。
- `VIS_需复核_Review`：未发现可见部分，同时涉及透明、动画、依赖或不支持的几何类型。

结果集合链接原对象，不复制网格、不移出原集合、不删除模型，也不自动保存工程。因为对象仍在原集合中，关闭结果集合的眼睛不一定会隐藏它们；请用面板的“选择内部候选”后按 `H` 隐藏检查，`Alt+H` 取消隐藏。

## 方法与设置

- **GPU ID**：将计算后的网格直接绘制到浮点离屏缓冲区，通过对象 ID 统计可见性；不启动完整渲染器，也不改材质。分辨率影响细小可见区域的发现能力。
- **BVH**：从模型外部向对象表面采样点发射射线，发现可见证据即保留该对象。表面采样预算影响细小区域的覆盖。
- **GPU + BVH**：GPU 粗筛后，只对未被发现的对象进行 BVH 复核。默认推荐。
- **Compare**：两种方法独立运行，取可见对象的并集；耗时及差异对象输出到 Blender 系统控制台。

增加方向数以覆盖狭窄开口；增加 GPU 分辨率及表面采样以复核细小零件。有限采样不能证明完全包围，分类也不考虑未来动画、折射路径、间接光或阴影贡献。

已隐藏、已排除或关闭渲染的对象会跳过；非网格和实例化/程序化几何支持有限。透明材质及包含节点组的材质保守地不参与遮挡。修改器通过 evaluated mesh 读取，不需要应用到原对象。

## 开发验证

仓库根目录运行 `python scripts/build_visibility_scanner.py` 生成安装包。使用 Blender Python 执行 `tests/visibility_scanner_blender.py` 验证射线、离屏绘制、取消和重复注册；该测试不会加载个人模型或保存 `.blend`。
